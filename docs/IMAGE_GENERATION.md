# 이미지 생성 방식을 정한 과정

시디과 그림체를 AI 캐릭터에 입히는 방법으로 두 가지를 비교함.

**1. 로컬 LoRA 학습 (실험만 하고 서비스에는 안 씀)**

- 시디과 원화에서 캐릭터(병아리) 이미지 10장을 뽑아 학습 데이터로 씀.
- 환경: RTX 4060 Ti 8GB, Stable Diffusion 1.5, OneTrainer.
- 설정 두 가지로 비교함.

| 설정 | V1 | V2 |
|---|---|---|
| LoRA Rank | 16 | 16 |
| LoRA Alpha | 1 | 16 |
| Learning Rate | 0.0001 | 0.00005 |
| Epochs | 60 | 30 |

- 학습 단계(0, 10, 20, 30 Epoch)별로 뽑아 보니 이런 문제가 반복됨. V2는 최종 30 Epoch까지 돌려도 그대로였음.
  - 눈이 지나치게 크고 원본과 위치가 다름
  - 머리 위 돌기가 과장되거나 여러 개 생김
  - 배경에 노란 도형이 반복해서 생김
  - 손과 발 모양이 무너짐
  - 흰 배경을 요청해도 갈색, 검정 배경으로 나옴
- 학습 전(0 Epoch)부터 원본과 다른 그림이 나와서, 기반 모델(SD1.5) 자체가 이 캐릭터를 잘 못 그리는 걸로 봄.
- V2가 더 나빠진 건 Alpha를 1 → 16으로 올려 학습 세기가 크게 늘어난 영향으로 추정함. Alpha만의 문제라고 확정하지는 못함.
- 결론: V1, V2 모두 최종 결과까지 확인했지만 지금 데이터 양, GPU, 기반 모델 조합으로는 서비스에 쓸 품질이 안 나와서 LoRA는 여기서 멈춤. 더 하려면 데이터셋 보강(선명한 정면, 측면 단독 포즈)과 더 좋은 기반 모델이 필요함.

**2. OpenAI 이미지 API + 참고 이미지 (채택)**

- 그림 만들 때마다 고른 그림체의 시디과 그림 2장을 참고 이미지로 같이 보내고, 프롬프트로 "그림체만 따라 하고 캐릭터는 새로 그려라"라고 지시함.
- 1장에 10~20초, 약 30~45원. 학습 없이 그림체 8개를 바로 쓸 수 있음.

**왜 2번을 골랐나**

| 비교 | OpenAI + 참고 이미지 | 로컬 SD1.5 LoRA |
|---|---|---|
| 이미지 품질 | 안정적 | 결과 불안정 |
| 새 업종 캐릭터 (떡볶이집, 카페 등) | 잘 됨 | 검증 못 함 |
| 그림체 추가 | 그림 2장 넣으면 끝 | 그림체마다 새로 학습 |
| 개발 상태 | 구현 완료 | 학습, 실행 환경 따로 필요 |
| 비용 | 장당 API 요금 | 로컬 GPU |

가게온의 목표는 병아리 하나를 똑같이 다시 그리는 게 아니라, 디자이너 그림체로 **여러 업종의 새 캐릭터**를 만드는 것이라서 2번이 맞다고 판단함. 앞으로는 LoRA보다 프롬프트, 그림체 유지율, 다시 만들기, 인쇄용 출력 품질을 개선할 계획.
